# Рацион+ → Telegram: фото + текст прямо из ChatGPT

**Цель:** отправил фотографию еды и граммовки в обычный чат ChatGPT → ChatGPT считает калории и белок → после твоего запроса самостоятельно публикует **эту же фотографию** и текст с эмодзи-прогресс-барами в Telegram-канале `@ration_sergey_post`. Никаких сторонних платных публикационных сервисов и повторного выбора снимка в Upload Studio.

**Как работает:** сервер Cloudflare Worker обрабатывает инструменты ChatGPT через стандартный MCP и получает прикреплённые пользователем фото в защищённой передаче `_meta["openai/fileParams"]`. Получает **временный download_url**, скачивает оригинал из OpenAI по HTTPS, проверяет файл и отправляет его в Telegram Bot API. Сами файлы в Cloudflare KV не сохраняются. Cloudflare KV хранит только суточные итоги и одноразовые OAuth-коды. Доступ защищён собственным OAuth 2.1 с PKCE; для привязки ChatGPT нужен один раз пароль владельца.

**Цена:** Telegram Bot API — бесплатная публикация для обычного частного канала, Cloudflare Workers + KV укладываются в бесплатные квоты при личном использовании, *не гарантируется* при выходе за лимиты. Расчёт КБЖУ делает сама подписка ChatGPT, отдельный OpenAI API не нужен.

## Настроить один раз

**1. Развернуть сервер — одной кнопкой.** Открой:

https://deploy.workers.cloudflare.com/?url=https://github.com/sergeygorbunov1998-dev/ration/tree/main/telegram-mcp

Войди в Cloudflare (можно через существующий GitHub), подтверди создание и развёртывание. Если требуется, выбери Worker `ration-telegram-mcp`. При развёртывании KV-хранилище `STATE` будет создано автоматически из `wrangler.toml`.

**2. Внести только два секрета.** В Cloudflare → Workers & Pages → `ration-telegram-mcp` → Settings → Variables and Secrets добавь как **Encrypted Secret**:

- `TELEGRAM_BOT_TOKEN`: токен **уже созданного** `@ration_sergey_bot`, который ты получал у BotFather. Если забыл, смотри @BotFather → /mybots → свой бот → API Token. Он уже администратор канала; ничего создавать заново не нужно.
- `OWNER_PASSWORD`: придумай самостоятельно длинный пароль из 16+ случайных символов; сохранить у себя, **никогда не отправлять в ChatGPT/GitHub**. Он понадобится **один раз** при подключении плагина.

После сохранения секретов дождись завершения развёртывания или нажми Redeploy. Настройки канала уже записаны в конфигурацию (публичный `@ration_sergey_post`), целей — 2350 ккал / 175 г белка.

**3. Подключить ChatGPT.** Скопируй адрес Worker из Cloudflare, например `https://ration-telegram-mcp.<account>.workers.dev`. В ChatGPT открой Plugins → кнопка `+` → **Add custom MCP server** (в некоторых интерфейсах: Settings → Plugins). Название: `Рацион Telegram`. Server URL: **адрес Worker + `/mcp`**. Выбери OAuth, если форма предлагает настройку. Нажми Connect. На странице авторизации введи `OWNER_PASSWORD` из Cloudflare.

С этого момента можно прикреплять оригинальные фото в ChatGPT и писать, например:

**«Творог 200 г, зефир 50 г. Посчитай калории и белок, покажи мне результат, затем опубликуй эти фото и расчёт в @ration_sergey_post через Рацион Telegram».**

Для сохранения полного контроля: можно сначала просить **«посчитай и подготовь, не публикуй»**, а когда всё верно — **«опубликуй»**. Отдельного окна Upload Studio, повторной загрузки файла и ежемесячного тарифа Upload-Post нет.

## Проверить, что действительно работает

1. Адрес `https://<worker>.workers.dev/health` должен вернуть `{"ready":true,...}`. Это доказывает наличие секретов и KV, **но не проверяет Telegram авторизацию**.
2. В ChatGPT с подключённым `Рацион Telegram` пришли фото тестовой еды и попроси опубликовать. Успешный ответ возвращает прямую ссылку на сообщение канала.
3. Если фото недоступно ChatGPT-инструменту, при `require_photo=true` сервер выдаст ошибку, а **не отправит текстовое сообщение вместо фото**.
4. Первая опубликованная запись нового дня создаёт дневной итог; для учёта старых приёмов попроси ChatGPT вызвать `set_daily_progress` и установить уже посчитанные ккал и белок.

## Безопасность и ограничения

- Никаких паролей или токенов в публичном GitHub. Секреты хранятся только в Cloudflare. После смены `OWNER_PASSWORD` существующие OAuth-токены перестанут работать. После смены токена BotFather потребуется переподключение Telegram через настройки.
- OAuth доступен только через подтверждённый пароль и только с редиректами ChatGPT. PKCE защищает обмен токенами; код авторизации одноразовый.
- Разрешены файлы до 9 МБ, не более 4 изображений в посте. Сервер ограничивает загрузку снимков доверенными HTTPS-хостами OpenAI и проверяет сигнатуру JPEG/PNG/WebP.
- Модель может ошибаться в калориях и граммовках. Для этикеток точнее читать сами значения; полная автономная публикация без проверки может закреплять ошибки.
- Дневной итог Cloudflare KV обладает **eventual consistency**: параллельные публикации в один момент могут конфликтовать; публикуй приёмы последовательно. Telegram не даёт идемпотентность отправки; `idempotency_key` защищает от большинства повторов, но сетевой сбой между постом и записью KV может оставить неопределённый статус.
- Инструмент `publish_meal` — реально публичное действие; его следует вызывать только по запросу пользователя и, при сомнительной оценке, после проверки.
- Эта версия не использует ранее созданное веб-приложение `Рацион+`: код изолирован в каталоге `telegram-mcp`.
- Вся идея **реалистична и проверена автоматическими тестами с подменёнными Telegram и OpenAI endpoints**. Пока Worker не развёрнут и пользователь не подключил собственный MCP-сервер, **живую отправку фотографии из ChatGPT считать проверенной нельзя**.

## Проверки

Запуск из `telegram-mcp/`:

```
node test.mjs
```

Эти тесты входят в `.github/workflows/quality.yml`: проверяют OAuth PKCE, защиту от неверного пароля, блокировку чужих callback URL, корректную схему `openai/fileParams`, получение фото через защищённый URL, реальный multipart-запрос в имитацию Telegram, дневные прогресс-бары и отсутствие дублей.

### Почему не просто Upload-Post?

У Upload-Post бесплатный лимит 10 публикаций/мес, далее Basic — $24/мес или $16/мес при годовой оплате (на ноябрь 2026). Для 3–4 приёмов еды в день это неразумная подписка. Встроенный Upload Studio требует ещё раз выбрать файл, поскольку его штатный инструмент не объявляет возможность напрямую принимать ChatGPT-attachments через `openai/fileParams`. Этот MCP-сервер прямо реализует недостающий приём файлов из чата.
